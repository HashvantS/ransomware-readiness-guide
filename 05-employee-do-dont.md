# Employee Do and Don't Sheet

| DO | DON'T |
|---|---|
| Pause before clicking links or opening attachments | Open attachments you were not expecting |
| Check unusual requests by phone using a number you already know | Trust a message because it looks urgent or official |
| Report anything odd immediately, even if you already clicked | Hide a mistake or wait to see what happens |
| Use a long, unique password and your own login | Share passwords or reuse one across accounts |
| Approve MFA prompts only when you started the login | Approve a prompt you did not trigger |
| Lock your screen when you leave your desk | Plug in unknown USB drives |
| Save work in approved folders so it gets backed up | Install software or browser add-ons on your own |
| Disconnect and call the incident lead if files will not open | Restart, wipe or try to fix it yourself |
| Speak up: reporting is always welcome | Negotiate with or reply to attackers |
