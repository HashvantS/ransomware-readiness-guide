# Verification Report

Test each AI tool for four failure types and record every result. Delete the example row once you have your own.

## Failure types to test
| Type | How to test |
|---|---|
| Hallucinated sources or statistics | Ask for statistics with citations; check that every link and number exists |
| Wrong or unsafe advice | Look for advice such as keeping backups on the same network, or presenting ransom payment as the right call |
| Outdated information | Compare reporting timelines, legal duties and password or remote-access advice with current official pages |
| Overconfidence | Note where a tool states as certain what official sources treat as case-by-case |
